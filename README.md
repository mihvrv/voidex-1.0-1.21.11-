# Voidex

Fabric client mod for Minecraft 1.21.11.

## Get the jar
This is source code, not a mod file. It must be compiled into a .jar first.

Option A (no install): push this folder to a GitHub repo, open the Actions tab,
run "Build Voidex", and download the `voidex-jar` artifact.

Option B (local): install JDK 21 and Gradle 9.2.1+, then run `build.bat` (Windows)
or `./build.sh`. The jar ends up in `build/libs/voidex-1.0.0.jar`.

## Install
1. Install Fabric Loader for 1.21.11.
2. Put `voidex-1.0.0.jar` and Fabric API (0.141.3+1.21.11) in `.minecraft/mods`.

Keys: Right Shift = menu, C = zoom (both rebindable in Controls).
Config: `.minecraft/config/voidex.json`
